## 🌟 Overview

**80s Movie Night Review** is a multi-page web showcase celebrating the golden era of practical effects, synthesizer soundtracks, and blockbuster cinema. The site features detailed retrospective reviews, VHS-style ratings, and an interactive, animated visual backdrop that channels 1980s arcade, sci-fi, and VHS culture.

Created as part of **JOU 324**, this project demonstrates modern semantic HTML5 and advanced pure-CSS visual design without relying on heavy external JavaScript frameworks.

---

## ✨ Features & Visual Highlights

- 🌆 **Atmospheric Synthwave Aesthetic:**
  - Multi-layer 3D-perspective neon grid floor and glowing horizon.
  - Glowing synthwave sun with stylized horizontal sunset blinds.
  - Silhouette mountains with glowing ridge lines and tropical neon palm trees.
- 🚀 **Pure CSS Sky & Airspace Animations:**
  - Twin fighter jets with dual contrails streaking across the sky.
  - UFO spacecraft flybys and twin shooting stars with staggered trajectories.
  - Sweeping multi-color searchlight beams (cyan, gold, magenta).
  - Ambient rolling fog layers and intermittent lightning flash effects.
- 📼 **Curated Retro Film Reviews:**
  - Interactive movie cards with hover effects and neon border highlights.
  - Film review pages complete with cast & director credits, commentary, release years, runtimes, and VHS ratings.
- 📻 **BBS Transmission Contact Terminal:**
  - Retro bulletin board system (BBS) themed contact form with callsig, frequency, and message inputs.
- 💎 **Glassmorphic UI Panels:**
  - Translucent content containers with high-contrast text, glowing borders, and modern accessibility-conscious contrast.
- 📱 **Mobile & Desktop Responsive:**
  - Fluid flexbox and grid layouts that adapt across modern screen sizes.
  - Supports modern browser View Transitions (`same-origin`).

## 🚀 Getting Started

### Option 1: View in Browser Directly
1. Clone or download the repository:
   ```bash
   git clone https://github.com/saabernathy/steven-basic-site.git
   cd steven-basic-site
   ```
2. Double-click `index.html` or open it with your preferred browser.

### Option 2: Run with a Local Static Server
If you prefer running a local server:

```bash
# Using Python 3
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.
